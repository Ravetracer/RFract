### Downloads

| System | File |
|--------|------|
| Linux x86_64 | `RFract-<version>-linux-x86_64.tar.gz` (see INSTALL.txt inside for the needed libraries) |
| Linux, any distribution | `RFract-<version>-x86_64.AppImage` (`chmod +x`, then run; `… cli` runs the command line tool) |
| Windows 10/11 x64 | `RFract-<version>-windows-x64.zip` |
| macOS, Apple silicon | `RFract-<version>-macos-arm64.zip` |
| macOS, Intel | `RFract-<version>-macos-x86_64.zip` |

The builds are not signed. On macOS remove the quarantine flag after moving the app to
/Applications: `xattr -dr com.apple.quarantine /Applications/RFract.app`. On Windows
SmartScreen may ask: "More info" › "Run anyway". Details in INSTALL.txt of each package.
