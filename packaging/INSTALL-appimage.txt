RFract @VERSION@ AppImage (Linux x86_64)
========================================

  chmod +x RFract-@VERSION@-x86_64.AppImage
  ./RFract-@VERSION@-x86_64.AppImage

The command line tool is inside too:
  ./RFract-@VERSION@-x86_64.AppImage cli info        (version, GPU, denoiser)

The AppImage brings the denoiser and the manual. It uses the system's graphics driver
(Vulkan), window libraries and, for movies, ffmpeg; see the Linux package's INSTALL.txt.
AppImages need FUSE 2 (libfuse.so.2); without it run with --appimage-extract-and-run.
On immutable systems (Bazzite, Silverblue, SteamOS) keep the file in your home folder.
